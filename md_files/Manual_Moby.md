Moby: modo de usar  
___  
Selecione livro e tema nas listas:  
  
✻ = Escolhe um tema aleatoriamente  
◀ = Move para o tema anterior  
✚ = Gera um novo texto para o tema  
▶ = Move para o próximo tema  
s  = Ouvir o tema selecionado  
?  = Modo de Usar & Manual do Usuário  
  
No navegador Google Chrome,  
use as setas Ctrl + ou Ctrl -  
para fazer Zoom da tela.  
  
Selecione palavra ou frase nos textos  
e Ctrl C / Ctrl V para copiar/colar.  
  
Use o botão direito do mouse para  
buscar textos/palavras no Google.  
  
Use Ctrl F para buscar nessa página.
