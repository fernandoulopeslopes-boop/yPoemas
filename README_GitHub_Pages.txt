GO ypoemas_com_br_GitHub_Pages

Arquivos:
- index.html
- CNAME
- .nojekyll
- README_GitHub_Pages.txt

Destino:
- GitHub Pages
- domínio público: ypoemas.com.br
- botão principal: https://ypoemas-machina.streamlit.app/

Uso:
1. Enviar estes arquivos para a raiz do repositório do site.
2. Ativar GitHub Pages em Settings > Pages.
3. Usar branch main e pasta /root.
4. Em Custom domain, usar: ypoemas.com.br.
5. No DNS do domínio, apontar ypoemas.com.br para o GitHub Pages.

Este pacote não altera a Machina/Streamlit.
O app continua em https://ypoemas-machina.streamlit.app/
O site é a porta de entrada pública.
